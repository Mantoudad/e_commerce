# STAT462 Data Mining Group Project

## Project Overview
This repository contains the data mining group project for **STAT462** at the University of Canterbury. The project focuses on exploratory data analysis (EDA), data cleaning, and predictive modeling using customer e-commerce data.

## Repository Structure

```text
├── E Commerce Dataset.xlsx              # Raw dataset used for analysis
├── stat462_s2_team_tuatara_project_v2.Rmd # Main R Markdown analysis script
├── e_commerce.Rproj                     # RStudio project file
├── .gitignore                           # Git ignore configurations
└── README.md                            # Project documentation
```
## Required R Packages
To run the analysis in stat462_s2_team_tuatara_project_v2.Rmd, ensure you have requested library installed by uncomment "install.packages" lines
